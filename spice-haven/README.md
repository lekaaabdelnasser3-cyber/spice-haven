# Spice Haven

Static website: HTML + CSS + a little JavaScript. No frameworks.

## Structure
spice-haven/
  index.html          home
  menu.html           menu
  about.html          about + contact (#contact)
  book-a-table.html   booking form + popup
  css/style.css       all styles (colours are variables at the top)
  js/main.js          mobile menu, time slots, booking popup
  images/             your photos (see images/README.txt)

## Run it
Double-click index.html, or use the Live Server extension in VS Code.
Without photos the site still works: each image has a warm gradient behind it.
